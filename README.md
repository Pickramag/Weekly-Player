### ⚙️ Возможности

| Функция | Описание |
| :--- | :--- |
| ☁️ **Интеграция SoundCloud** | Быстрый импорт и стриминг любимых плейлистов и треков напрямую из SoundCloud без лишних шагов |
| 📁 **Локальная медиатека** | Удобное добавление и организация собственной офлайн-коллекции аудиофайлов с вашего компьютера |
| ⚡ **Архитектура Tauri** | Минимальное потребление оперативной памяти и мгновенный запуск за счет легковесного бэкенда на Rust вместо тяжелого Chromium |
| 🎨 **Минималистичный UI** | Чистый, адаптивный и эстетичный интерфейс, созданный на стеке React + TypeScript |
| 🎛 **Удобное управление** | Быстрая навигация по трекам, управление воспроизведением и фоновый режим |

---

### 🛠 Стек технологий

- **Desktop Core:** [Tauri](https://tauri.app/) (Rust)
- **Frontend UI:** [React](https://react.dev/) + [TypeScript](https://www.typescriptlang.org/)
- **Аудио-источники:** SoundCloud API & Локальная файловая система

### 💻 Сборка из исходников

Если вы хотите запустить проект локально или собрать самостоятельно:

```bash
# 1. Клонируйте репозиторий
git clone https://github.com/Pickramag/Weekly-Player.git
cd Weekly-Player

# 2. Установите зависимости
npm install

# 3. Запустите проект в режиме разработки
npm run tauri dev

# 4. Соберите итоговый установщик
npm run tauri build
```
