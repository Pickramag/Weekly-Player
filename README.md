### ✨ Features

- 🎧 **SoundCloud Integration:** Seamlessly import and stream your favorite playlists directly from SoundCloud.
- 📁 **Local Audio Support:** Add and organize your own offline music library with ease.
- ⚡ **Lightweight & Fast:** Built on top of **Tauri**, ensuring minimal RAM usage and rapid startup compared to traditional Electron apps.
- 🎨 **Modern Minimalist UI:** Clean, responsive, and distraction-free interface crafted with React & TypeScript.

---

### 🛠 Tech Stack

Weekly is built using modern web and native desktop technologies:

| Layer | Technology |
| :--- | :--- |
| **Desktop Framework** | [Tauri](https://tauri.app/) (Rust-powered native performance) |
| **Frontend Library** | [React](https://react.dev/) |
| **Language** | [TypeScript](https://www.typescriptlang.org/) |
| **Audio Source** | SoundCloud API & Local Filesystem |

### 💻 Development & Building from Source

If you want to run or build the project locally:

1. **Clone the repository:**
   ```bash
   git clone https://github.com/Pickramag/Weekly-Player.git
   cd Weekly-Player
   ```

2. **Install dependencies:**
   ```bash
   npm install
   # or
   pnpm install
   ```

3. **Run development mode:**
   ```bash
   npm run tauri dev
   ```

4. **Build release package:**
   ```bash
   npm run tauri build
   ```
